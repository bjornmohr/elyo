# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub issues. Use the `gh` CLI from this clone so the repository is inferred from `origin`.

## Conventions

- Create issues with `gh issue create`.
- Read issues and comments with `gh issue view <number> --comments`.
- Apply or remove triage labels with `gh issue edit`.
- Close completed issues with `gh issue close` and a concise completion comment.
- GitHub issues and pull requests share one number space; resolve ambiguous references before acting.

## Pull requests as a triage surface

External pull requests are not a request surface. Maintainer and contributor PRs remain normal delivery artifacts rather than entering the issue-triage state machine.

## Publishing

When an engineering skill says to publish a PRD or ticket, create a GitHub issue and apply the requested triage label.
